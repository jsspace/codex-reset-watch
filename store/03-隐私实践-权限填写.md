# Chrome Web Store Privacy practices · paste-ready answers

These answers describe the current `extension/` code. Recheck them if the extension changes before submission.

**Single purpose:** Show public Codex reset records and 24/48-hour forecasts in the browser toolbar, with optional local desktop alerts.

**Permission justifications:**

| Permission | Paste-ready justification |
| --- | --- |
| `alarms` | Check the public forecast and timeline on a one-minute schedule while the browser is running. |
| `storage` | Keep the latest successful public snapshot, display preferences, and notification delivery state locally so the popup loads immediately and alerts do not repeat unnecessarily. |
| `notifications` | Show optional desktop alerts for public reset announcements, active signals, or a forecast crossing the user's notification threshold. |
| `offscreen` | Play a brief locally generated sound only when the user has enabled audio alerts. Manifest V3 service workers cannot play audio directly. |
| Host `https://codex-reset.com/*` | Fetch the public, read-only forecast and timeline APIs that supply all displayed data. No other host access is requested. |

**Remote code:** No. The extension fetches JSON data, not executable scripts; all JavaScript is bundled in the uploaded ZIP.

**User data disclosure:** The extension does not collect or transmit personal user data to the developer. Settings, public data cache, and notification state are stored locally. Direct API requests expose ordinary network metadata to `codex-reset.com` as described in the privacy policy. Select dashboard data-category checkboxes according to the current dashboard wording; do not claim the provider receives no network metadata.
