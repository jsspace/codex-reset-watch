# Codex Reset Privacy Policy

Last updated: 2026-10-28

Codex Reset is a browser extension that displays public Codex reset records and forecasts. It is an independent community tool and is not affiliated with OpenAI or codex-reset.com.

## Information the extension uses

- The extension requests public forecast and timeline data from `https://codex-reset.com/`. Like any direct web request, the data provider may receive normal network information such as your IP address and browser user agent. The extension sends no account credentials or extension preferences in those requests.
- The extension stores your language, appearance and notification preferences, the last successful public data snapshot, and notification delivery state in `chrome.storage.local` on your device. It does not use `chrome.storage.sync`.
- The extension does not read your Codex account, browser history, visited page content, passwords, or payment information. It has no analytics, advertising, or developer-operated data collection endpoint.

## How information is used

The public data is used to update the toolbar badge and popup and, if enabled, to show desktop notifications. The optional sound is generated locally. Stored preferences and snapshots are used only to run these extension features. The extension does not sell or share locally stored information.

Source links may open `codex-reset.com` or the original public post in a new tab when you choose to click them. Those sites apply their own privacy practices.

## Retention and control

The latest successful public snapshot and preferences remain in local extension storage until replaced, cleared through Chrome's extension data controls, or removed when the extension is uninstalled. Notification delivery entries are capped at 100. You can disable notifications and sound in the extension settings.

## Contact

For privacy questions, open an issue at [github.com/jsspace/codex-reset-watch/issues](https://github.com/jsspace/codex-reset-watch/issues).

# Codex Reset 隐私说明

更新日期：2026-10-28

Codex Reset 是展示公开 Codex 重置记录与预测的浏览器扩展。它是独立社区工具，与 OpenAI 或 codex-reset.com 无隶属关系。

- 扩展直接从 `https://codex-reset.com/` 请求公开数据。与普通网页请求一样，数据提供方可能收到 IP 地址和浏览器 User-Agent 等网络信息；扩展不会发送账户凭证或个人设置。
- 语言、外观与通知设置、上次成功获取的公开数据快照，以及通知投递状态，保存在设备上的 `chrome.storage.local`；不使用同步存储。
- 扩展不读取 Codex 账户、浏览历史、网页内容、密码或支付信息；没有分析、广告或开发者运营的数据收集端点。
- 公开数据用于工具栏角标、弹窗和用户启用的桌面通知。可选提示音在本地生成。扩展不出售或共享本地保存的信息。
- 用户主动点击来源链接时，会打开数据提供方或原始帖文；这些网站适用其各自的隐私规则。
- 本地快照和设置在更新、通过 Chrome 清除扩展数据或卸载扩展时删除。通知投递记录最多保留 100 条。可在设置中关闭通知和声音。

隐私问题请通过 [GitHub Issues](https://github.com/jsspace/codex-reset-watch/issues) 联系。
